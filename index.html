Peer-to-Peer File Sharing Infrastructure

2022

Problem: Centralized file transfers over local networks suffer from bandwidth bottlenecks and single-point server failures.
Architecture: Engineered a custom multi-threaded Python TCP/UDP socket network protocol featuring asynchronous chunk verification and direct peer discovery.
Trade-off: Accepted initial peer discovery latency to achieve maximum throughput across local subnet links without reliance on external cloud coordination.

C++ Deep Learning Collaborative Filtering Recommender

2023

Problem: Standard Python-based recommendation scripts fail to scale under high-concurrency matrix operations.
Architecture: Developed a bare-metal C++ recommendation engine utilizing optimized sparse matrix representations and parallel gradient descent for low-latency scoring.
Trade-off: Sacrificed rapid prototyping speed for sub-millisecond execution times and minimal memory footprints under large item sets.

Assistive Android System with Eye-Tracking

2022

Architecture: Designed a native Android application integrating real-time gaze estimation algorithms using mobile front-facing camera frames.
