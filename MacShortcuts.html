Mac Keyboard Shortcuts

  • Baha Erdoğan
  • Technology

Moving from Windows to macOS is mostly painless, until your fingers reach for Ctrl and nothing happens. I put this list together to make that transition quicker. It isn't every shortcut macOS has, just the ones that save the most time day to day. If you spot a mistake, send me an email and I'll fix it.

First, the keys

Most Windows shortcuts carry over if you swap one key: where Windows uses Ctrl, the Mac uses ⌘ Command. The Windows Alt key corresponds to ⌥ Option. The Mac also has a separate ⌃ Control key, which is used much less often, mainly in Terminal and for a few system functions.

Everyday shortcuts

  • ⌘ + C – Copy
  • ⌘ + X – Cut
  • ⌘ + V – Paste
  • ⌘ + Z – Undo
  • ⌘ + Shift + Z – Redo
  • ⌘ + A – Select all
  • ⌘ + Q – Quit the app (closing the last window usually doesn't)
  • ⌘ + W – Close the window
  • ⌘ + Tab – Switch between apps
  • ⌘ + Space – Spotlight search
  • Control + ⌘ + Q – Lock the screen

Finder and files

  • ⌘ + N – New Finder window
  • ⌘ + Shift + N – New folder
  • ⌘ + Delete – Move to Trash
  • ⌘ + Shift + Delete – Empty Trash
  • Space – Quick Look preview of the selected file
  • ⌘ + Option + Esc – Force quit apps

Screenshots and screen recording

  • ⌘ + Shift + 3 – Capture the whole screen
  • ⌘ + Shift + 4 – Capture a selected area (press Space afterwards to capture a single window)
  • ⌘ + Shift + 5 – Screenshot and recording options
  • ⌘ + Shift + 6 – Capture the Touch Bar (on Macs that have one)

In the browser

  • ⌘ + T – New tab
  • ⌘ + W – Close tab
  • ⌘ + Shift + T – Reopen the last closed tab
  • ⌘ + R – Reload the page
  • ⌘ + L – Jump to the address bar
  • ⌘ + D – Bookmark the page

Moving around in text

  • Option + → / ← – Move the cursor one word
  • ⌘ + → / ← – Jump to the end or start of the line
  • ⌘ + ↑ / ↓ – Jump to the top or bottom of the document
  • ⌘ + Shift + → / ← – Select to the end or start of the line
  • Option + Shift + → / ← – Select word by word

Windows and Mission Control

  • Control + ↑ – Open Mission Control
  • Control + ↓ – Show all windows of the current app
  • ⌘ + H – Hide the current app
  • ⌘ + M – Minimise the window
  • ⌘ + Option + M – Minimise all windows of the current app
  • Control + ⌘ + F – Toggle full screen

A few more

  • ⌘ + , (comma) – Open the app's settings
  • ⌘ + Option + D – Show or hide the Dock
  • Control + ⌘ + Space – Emoji and symbols
  • Fn (Globe) + Q – Quick Note (macOS Monterey and later)

For developers and power users

Windows, tabs and Finder

  • ⌘ + ` – Switch between windows of the same app
  • ⌘ + Shift + [ / ] – Previous or next tab in most apps
  • ⌘ + Option + C – Copy the selected file's path in Finder
  • ⌘ + Shift + . (period) – Show or hide hidden files in Finder
  • ⌘ + Option + Shift + V – Paste and match style (many apps, such as Chrome and Slack, also accept ⌘ + Shift + V)

Terminal

  • Control + A – Jump to the start of the line
  • Control + E – Jump to the end of the line
  • Control + U – Delete the line (in zsh, the default shell, the whole line; in bash, everything before the cursor)
  • Control + K – Delete from the cursor to the end of the line
  • Control + L – Clear the screen
  • Control + R – Search the command history
  • ⌘ + K – Clear the Terminal window, including the scrollback

Code editors (VS Code, Xcode)

  • ⌘ + P – Quick open a file (VS Code; in Xcode it's ⌘ + Shift + O)
  • ⌘ + Shift + F – Search the whole project
  • ⌘ + Option + F – Find and replace
  • ⌘ + Shift + [ / ] – Switch between open tabs
  • ⌘ + Shift + X – Extensions panel (VS Code)
  • ⌘ + / – Comment or uncomment the line

Make your own

If an app is missing a shortcut you want, you can add one yourself under System Settings → Keyboard → Keyboard Shortcuts → App Shortcuts. Type the exact name of the menu item, pick a key combination, and it works like a built-in one.
